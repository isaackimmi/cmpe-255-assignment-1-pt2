METHOD / CRISP-DM

From question to handoff

A compact view of the experiment lifecycle.

01⌁

Business
understanding

Choose a model that can rank malignant vs. benign cases reliably.

02◌

Data
understanding

Inspect 569 rows, 30 numeric features, and a binary target.

03◇

Data
preparation

Use a stratified, reproducible 80/20 train-test split.

04✣

Modeling

Compare four CPU-safe sklearn estimators; AutoGluon is optional.

05◒

Evaluation

Rank only on untouched test ROC-AUC, with accuracy and fit time.

06↗

Deployment

Review the winning model, then validate with repeated CV before production.

REPRODUCE THE RUN

Keep the loop
moving.

Everything here is generated locally. Re-run the experiment, refresh the artifacts, and reload this page.

01

Install

python3 -m pip install -r requirements.txt

Optional: add AutoGluon separately when the environment supports it.

02

Run fallback

python3 src/run_experiment.py --no-autogluon

Fast, deterministic sklearn comparison for CPU-only environments.

03

Serve UI

python3 -m http.server 8000

Open http://localhost:8000 in your browser.

04

Test

python3 -m pytest -q

Verifies reproducibility and ranked artifact output.
